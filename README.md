# Finance Manager

Projeto em Python para gerenciamento financeiro, com telas de acesso, cadastro,
painel principal e controle de contas.

## Tecnologias utilizadas

- **Python:** linguagem de programacao principal utilizada no desenvolvimento do
  sistema, escolhida por sua simplicidade, facilidade de aprendizado e grande
  quantidade de bibliotecas disponiveis.
- **Tkinter:** biblioteca nativa do Python utilizada para a criacao da interface
  grafica do sistema, permitindo o desenvolvimento das telas de acesso,
  cadastro, painel principal e controle de contas a pagar.
- **SQLite:** banco de dados utilizado para armazenar as informacoes do sistema,
  como usuarios, categorias, status e contas cadastradas. Foi escolhido por ser
  leve, pratico e adequado para aplicacoes de pequeno e medio porte.
- **Pandas:** biblioteca utilizada para organizacao e tratamento dos dados
  exibidos no dashboard, principalmente na construcao da base de informacoes
  usada nos graficos financeiros.
- **Matplotlib:** biblioteca utilizada para a geracao dos graficos do dashboard,
  possibilitando a visualizacao das informacoes financeiras de forma mais clara
  e intuitiva.
- **Pillow:** biblioteca utilizada para manipulacao e exibicao de imagens na
  interface, especialmente no carregamento da imagem de fundo das telas de acesso
  e cadastro.
- **VS Code:** ambiente de desenvolvimento utilizado para escrever, organizar e
  editar os arquivos do projeto.
- **Git:** ferramenta de versionamento utilizada para controlar as alteracoes
  realizadas no codigo-fonte durante o desenvolvimento.
- **GitHub:** plataforma utilizada para armazenar o repositorio do projeto,
  facilitar o compartilhamento dos arquivos e permitir o acompanhamento das
  versoes do sistema.
- **PowerShell:** terminal utilizado para executar comandos, testar o sistema,
  instalar bibliotecas e realizar operacoes relacionadas ao projeto.
